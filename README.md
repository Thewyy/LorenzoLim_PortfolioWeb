# Lorenzo Lim — Portfolio Website

A responsive, static portfolio starter built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `lorenzo-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
This is an initial design and content scaffold. Replace the abstract project artwork and photography placeholders with your own images. Verify all project descriptions and add your actual contributions, dates, certificates, and badge links.

Suggested image locations:
- `assets/images/projects/` — Math Conquest, Tech Vault, web design, and 3D project images
- `assets/images/photography/` — model/mecha and landscape photographs
- `assets/documents/` — resume PDF and other public portfolio documents

When adding images, use descriptive filenames and optimized JPG/WebP files. Do not publish private student records or documents containing sensitive personal information.

## GitHub Pages
GitHub Pages can publish this static site from a GitHub repository. For a personal account site, GitHub's standard repository naming format is `USERNAME.github.io`. Configure the publishing source in the repository's Settings → Pages.

Official documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## Notes
- Theme toggle switches between dark and light modes and remembers the visitor's choice in local storage.
- Navigation collapses on smaller screens.
- The site uses Google Fonts; a system-font fallback remains available if those fonts cannot load.
- No backend or build step is required.
